## 💻 Getting Started Locally

No package installations (`npm install` or `pip install`) are required to run this portfolio.

### 1. Clone the repository
```bash
git clone https://github.com/SanampalliPavanKalyan04/portfolio.git
cd portfolio
```

### 2. Configure Local Asset Paths
Ensure your image and resume files are stored in your root or `assets/` folder and update `index.html` references accordingly:
```html
<!-- Update relative paths -->
<img src="./assets/Pavan_Image.jpeg" alt="Sanampalli PavanKalyan" />
<a href="./assets/Pavan_Resume.pdf" download>RESUME</a>
```

### 3. Open in Browser
You can launch `index.html` directly, or use VS Code's **Live Server** extension:
```bash
# Using Python's built-in static HTTP server
python -m http.server 8000
```
Then visit [`http://localhost:8000`](http://localhost:8000) in your browser.
